# KaryaCNC - Agent Documentation

## Project Overview

KaryaCNC is a **CNC (Computer Numerical Control) machine control application** built with [Wails](https://wails.io/) (Go backend + HTML/JS frontend). It provides a desktop GUI for controlling CNC machines, laser cutters, and plasma cutters.

The application was migrated from Tauri (Rust) to Wails (Go) while preserving the original JavaScript frontend code through a compatibility layer.

### Key Features
- **G-code Editor**: Full-featured editor with syntax highlighting (Ace Editor)
- **Machine Control**: Real-time TCP connection to CNC machines for position tracking and job monitoring
- **WebSocket Server**: Receives G-code from external applications (e.g., Inkscape extension)
- **File Upload**: HTTP multipart upload of G-code files to machines
- **SVG Nesting**: Integrated nesting tool for optimizing material usage
- **Inkscape Extension**: Python extension for sending paths directly from Inkscape
- **Multi-machine Support**: Laser, CNC Router, Plasma cutter modes

- **Language**: Go 1.23+
- **Framework**: Wails v2.11.0

- **UI**: Vanilla HTML/CSS (no framework)
- **Libraries**:
  - Ace Editor - G-code editing

  - Infinite Canvas - Zoomable canvas for preview

### External Tools
- **Inkscape Extension**: Python 3 with `inkex` module
- **Nesting Tool**: Pure JavaScript with Web Workers

### Communication Patterns

#### Frontend → Backend (Commands)
Calls are made through `window.invoke(command, args)`:
- `upload_file` - Upload G-code file to machine
- `proxy_request` - HTTP proxy to machine
- `start_ws_server` - Start WebSocket server
- `start_telegram_server` - Start Telegram bot endpoint
- `connect_to_machine` - TCP connect to CNC
- `disconnect_from_machine` - Close TCP connection
- `start_receiving` - Start receiving machine data
- `install_inkscape_extension` - Copy extension files

#### Backend → Frontend (Events)
Events are received via `window.listen(event, callback)`:
- `machine-position` - Real-time position update (X, Y, Z, velocity)
- `machine-job` - Job status update (name, status, progress)
- `WS_SERVER_STARTED` - WebSocket server ready
- `WS_MESSAGE_RECEIVED` - G-code received via WebSocket
- `WS_CLIENT_DISCONNECTED` - Client disconnected
- `TELEGRAM_REQUEST` - Telegram bot message received

### CNC Binary Protocol
The backend communicates with CNC machines using a binary protocol:
- **Header**: 2 bytes (little-endian)
  - Bits 0-2: Message type (3 bits)
  - Bits 3-15: Payload length (13 bits)
- **Type 1**: Machine Position (17 bytes payload)
  - X, Y, Z: float32 (4 bytes each)
  - Velocity: float32 (4 bytes)
  - MoveID: uint8 (1 byte)
- **Type 2**: Machine Job (66 bytes payload)
  - Name: 64 bytes (null-terminated string)
  - Status: uint8
  - Progress: uint8

## Code Organization

### Backend (app.go)

| Method | Purpose |
|--------|---------|
| `UploadFile()` | HTTP multipart file upload to CNC machine |
| `ProxyRequest()` | HTTP GET proxy |
| `StartWSServer()` | WebSocket server for external G-code |
| `StartTelegramServer()` | HTTP server for Telegram bot webhooks |
| `ConnectToMachine()` | TCP connection to CNC |
| `DisconnectFromMachine()` | Close TCP connection |
| `StartReceiving()` | Start binary protocol parser |
| `InstallInkscapeExtension()` | Copy extension to Inkscape folder |

### Frontend (public/)

| File | Purpose |
|------|---------|
| `main.js` | Event listeners, WebSocket setup, machine connection |
| `cnc.js` | CNC control, file upload, G-code generation |
| `serial.js` | Serial communication, G-code sender |
| `gcodex.js` | G-code parsing and processing |
| `wails-runtime.js` | Tauri API compatibility layer |

## Development Conventions

### Code Style
- **Go**: Standard Go formatting (`gofmt`)
- **JavaScript**: ES6+, no strict linting configured
- **Indent**: 4 spaces (JavaScript), tabs (Go)

- Backend: Struct fields with `sync.Mutex` for thread safety

## Security Considerations

### Network Security
- WebSocket server binds to `0.0.0.0` (all interfaces) - ensure firewall rules
- No authentication on WebSocket/TCP connections - runs in trusted network
- HTTP servers run on localhost ports

### File System
- Inkscape extension writes to user's home directory (`AppData/Roaming/inkscape/extensions`)
- File uploads use multipart form with size limits (32MB)

### Input Validation
- SVG data is sanitized (xmlns attributes cleaned)
- Binary protocol has fixed-length parsing
- G-code parsing is client-side

## Notes for AI Agents

1. **Frontend Changes**: Modify files in `frontend/public/` not `frontend/src/`
2. **Backend Changes**: All Go code is in `app.go` (single file architecture)
3. **Adding Commands**: 
   - Go: Add method to `App` struct in `app.go`
   - JS: Add case in `wails-runtime.js` `invoke()` function
4. **Events**: Use `runtime.EventsEmit(a.ctx, "event-name", data)` in Go
5. **Build Required**: After Go changes, run `wails dev` or `wails build` to see changes
6. **No Tests**: This project has no automated test suite - rely on manual testing
